# Project Brief

## Overview
Chromatik is a modern **beat marketplace** inspired by the *Chromatic Scale*, emphasizing flexibility, expressiveness, and a creator-first approach. It serves as a platform for buying and selling beats/instrumentals.

## Core Requirements
- **Beat Marketplace**: Users can browse, listen to, and purchase beats.
- **Creator Focus**: Tools for producers to upload and manage their beats.
- **Modern UX**: A responsive, high-quality user interface.
- **Secure Transactions**: Safe payment and licensing processing (implied).

## Goals
- Provide a "premium" feel to the beat buying experience.
- Ensure robust creator tools.
- Maintain a scalable and maintainable codebase using modern tech stacks (Vue 3, Node.js, TypeScript).
